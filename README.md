# 《谁是人机》单人可交互 Web Demo

知乎官方 Hackathon 原型：一个人即可完成阅读、三轮写作、四次投票、身份揭晓、积分结算、关系卡回看与再来一局。

## 本地运行

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址。页面状态保存在浏览器 `localStorage`，刷新会恢复当前演示局；顶部“退出试玩”或演示控制栏“重置”可清空本局并返回首页。

## 验证命令

```bash
npm test
npm run build
```

测试覆盖用户可见字符计数（含组合 emoji）、50/51 字边界、空白校验、PRD 第 9 节计分票型、AI 选票过滤、关系卡优先级、禁止自投、投票锁定、第三轮两次投票隔离和重新开局状态清理。

## 实现说明

- React + TypeScript + Vite 前端，使用显式阶段状态机管理流程。
- 当前用户可以实际输入、提交和投票；其余两名“真人席位”和一个“AI 席位”使用本地预设脚本。
- 四席使用同一套刘看山基础形象的蓝色连帽衫、绿色背带裤、黄色针织衫和紫色运动外套变体。
- 计分只使用三名真人席位的选票，AI 单独展示且不进入真人排行榜。
- 第三轮问题质量票与最终身份票分开存储；关系卡只依据最终身份票和真实质量票生成。
- “复制”仅写入剪贴板，不会伪装成已发布到知乎。

## 文案维护

所有用户可见文案统一记录在 [`文案总表.md`](./文案总表.md)。后续修改文案时，界面代码与该文档必须同步更新并一同提交。

## Demo 边界与安全限制

这是前端单人演示，并非真实匹配：没有知乎账号、多人网络、真实模型调用、排行榜、支付或平台发布接口。

身份、未公开内容和选票目前都存在本地前端状态中，因此**不具备正式服务端的身份保密能力**。真实多人版必须由服务端保管控制者映射、AI 身份、未公开提交和未公开选票，并由服务端完成阶段裁剪、禁止自投、幂等提交与结算。
